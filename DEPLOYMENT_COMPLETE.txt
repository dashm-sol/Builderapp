                        🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Page shows 404:
  → Wait 5-10 minutes for GitHub Pages to propagate
  → Refresh page and clear browser cache

Changes not showing:
  → Clear browser cache (Ctrl+Shift+Del)
  → Hard refresh (Ctrl+Shift+R)
  → Verify npm run deploy completed successfully

Build fails:
  → Run: npm install
  → Run: npm run build
  → Check for errors in console output

Deploy fails:
  → Verify git is up to date: git status
  → Ensure all changes are committed: git add . && git commit
  → Try deploy again: npm run deploy
